# George Roșu — Portfolio Website

Official portfolio for **George Roșu**, commercial photographer and videographer based in Galați, Romania.

- **Stack**: React 19, TanStack Start, TanStack Router, Tailwind CSS, TypeScript, Vite.
- **Production URL**: [https://georgerosu.eu](https://georgerosu.eu)
- **Contact**: 26georgerosu@gmail.com | +40 746 900 286

## Scripts

- `bun run dev`: Start local development server
- `bun run build`: Build production bundle and generate sitemap
